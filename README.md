# libs-arc-ui

`libs-arc-ui` 是一个面向 **Paper / Folia** 服务端的空间展示前端库（基于 Minecraft 展示实体）。它专为追求极致空间排版精度与原版零模组视觉体验的**开发者**打造。

---

## 它能做什么？

* **零模组空间 UI 构建**：无需客户端模组，即可在世界任意三维空间中构建高精度的面板、卡牌、全息界面与立绘展示。
* **多层级空间嵌套**：支持无限层级的父子组结构，通过局部坐标系实现复杂 UI 组件的整体位移、缩放与绕轴旋转。
* **多材质与富文本渲染**：
* 支持纯色块与多图层遮挡控制。
* 支持自定义资源包字体、多行富文本，以及无缝接入 **CraftEngine** 图片与图集混排。
* 支持真三维方块模型展示，自由调整尺寸与朝向。


* **热重载与多线程安全**：原生适配 Folia 区域线程调度，支持配置文件实时热更新，修改即见效果，不污染世界存档。

**实战验证**：开发者已基于 `libs-arc-ui` 完整实现了 **UNO 卡牌** 与 **三国杀卡牌** 桌面级插件，在纯原版客户端下呈现出了极具冲击力的立体牌桌与卡牌交互视觉效果。

## 它做不了什么？

* **不包含交互与逻辑层**：它是一个**纯静态展示前端**，不提供点击判定、碰撞箱、按钮事件、指令系统或逐帧动画循环。交互逻辑（如射线检测、状态机）需要由你的业务插件自行接管。
* **没有可视化编辑器**：它**不是**所见即所得的拖拽式 UI 工具，也没有内置的预览面板。

---

## 开发者须知（重要）

* **硬核的纯数学驱动**：`libs-arc-ui` 本质上是一个空间变换与矩阵计算库。从多层级的局部坐标偏移、欧拉角旋转顺序，到绕自身/父节点公转的枢轴计算，**非常考验开发者的空间想象力与线性代数功底**。
* **不适合 Vibe Coding（AI 盲写）**：由于缺乏所见即所得的视觉反馈，大语言模型（AI）无法凭空“脑补”出复杂的三维空间排版与最终的视觉美感。除非你为该库额外接入了可视化预览器或定制了专用的 MCP 空间校验工具，否则请不要指望直接通过 AI 提示词生成惊艳的 UI 布局。
